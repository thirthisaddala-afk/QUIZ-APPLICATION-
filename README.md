# Quiz Application

An interactive quiz application built using HTML, CSS and JavaScript.

## Features

- Multiple-choice questions
- Instant answer feedback
- Correct and wrong answer indication
- Score calculation
- Restart quiz option
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

Open `index.html` in a web browser and start the quiz.

## Project Structure

- index.html
- style.css
- script.js
- README.md
